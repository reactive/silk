# @reactive/silk-native

## 0.1.0

### Minor Changes

- 1115c4a: Springs join the `motion` tokens: `snappy`, `brisk` and `smooth` are `Spring`s (`durationMs`, `bounce`) for position and size, beside the `fast`/`normal`/`slow` fades. The web gets `--silk-motion-{snappy|brisk|smooth}-duration-ms` and `-easing`; silk-native adds `springTo` (a spring that keeps a release speed) and `useMotion` (a token as a Reanimated transition), and the bottom sheet springs on `motion.smooth`.

  **Breaking:** a full `motion` literal now needs `snappy`, `brisk` and `smooth` (e.g. `snappy: { durationMs: 250, bounce: 0.15 }`), and a loop over `motionNames` that reads `.easing` must check `isSpringName(name)` first.

- 524ee2d: Show a keyboard focus ring on native controls. Adds `Pressable`, a drop-in for React Native's that outlines itself in the theme's `focusRing` color while focus is visible: on the web, only when the browser's `:focus-visible` matches (Tab, not a click); on native, on any focus. `Button`, pressable `Card` and `Surface`, `Checkbox`, `Switch` and `RadioGroup.Item` use it, ringing in their tone or in `danger` when invalid, as on web. `style` and `children` functions also receive `hovered` and `focusVisible`. Adds the `mapFocusRingStyle` mapper.
- 1115c4a: **Breaking:** install `react-native-gesture-handler`, `react-native-reanimated` and `react-native-worklets` as peers, with the worklets Babel plugin (Expo's preset adds it). `@reactive/silk-native/gesture`'s `Dialog` → `@reactive/silk-native`'s `Dialog` (type `GestureDialog` → `DialogNamespace`), same API; `/gesture` stays one release as a deprecated alias.

  The root `Dialog`'s bottom sheet drags on the UI thread, and `Dialog.ScrollView` hands a pull-down at its top to the sheet.

- 86729e5: Add `MotionList` and `MotionView` to `silk-native`: a list whose items glide to where a change moves them on the theme's `brisk` spring, keeping their speed when interrupted, and fade in (and out, on the web) on the theme's `normal` and `fast` durations with the change you name. Add `sampleSpringOffsets` to `silk-core`, which samples a spring from any offset and speed.
- c3b0184: Stop native Spinner and Progress from flashing their reduced-motion appearance on mount. React Native exposes the OS preference only through async `AccessibilityInfo`, so the first render is now `'unresolved'`: motion stays suppressed, but the full-motion visuals render until the OS confirms `'reduced'`. Adds `useMotionPreference` for components that swap appearance (not just animation) and caches the OS answer so only the first mount is ever unresolved.
- 71d1fc5: Add `Dialog` (centered, or a bottom sheet), `Popover` and `Listbox` overlays to `@reactive/silk-native`, with their `SilkDefaults` keys and mappers. On the web, `Popover` is non-modal (a hover-opened menu keeps working) and moves focus in as it opens unless `Popover.Content`'s `onOpenAutoFocus` calls `preventDefault()`. `Listbox.ItemText` colors custom item text as the label, or with `tone="secondary"` as a description; both dim on a disabled item. It adds a `placement` axis (`center` | `bottom`) on `dialogRecipe` that web `Dialog.Content` styles too. Also fixes `data-*` attributes on native components under react-native-web, which it had been dropping.
- 7ff48de: Add `Pager` (`Root`, `Page`, `usePagerIsActive`), a controlled swipe between pages; `useFlickGesture`; and `gestureConventions`, so apps' own gestures match Silk's. On the web, dragging a bottom sheet with a mouse no longer also presses the button the drag began on.
- 0697934: Add `Slider` to `@reactive/silk-native`, with web `Slider`'s contract: one number per thumb (`value` / `defaultValue` arrays, so a range has two), `onValueChange` / `onValueCommit`, `min` / `max` / `step`, `minStepsBetweenThumbs`, `orientation`, `dir`, `inverted`, `thumbLabels` and `thumbValueText`. Drag a thumb or press the track; on the web, arrow, Page, Home and End keys move a focused thumb; screen readers adjust it a step at a time. `children` draw over the track and under the thumbs, and `useSliderMarkStyle()` inside them places a mark where a thumb sits at a value. Adds the `Slider` `SilkDefaults` key.
- b341f2b: `springTo` takes `speedAway: 'drop'`: a starting speed (given, or carried from the animation it replaces) that points away from the target is dropped, so the spring starts from rest. With `overshootClamping`, the value then stays between where it starts and the target. `Switch` and `Slider` settle with both, and a `Pager` release drops an away speed this way too. The default, `'keep'`, is unchanged.
- f17d613: `Switch` drags on the UI thread: its thumb follows a sideways drag and, let go, lands on the nearer end or the way a fling goes, springing there on the theme's `snappy` spring, carrying the finger's speed when it heads that way, without passing the track's ends. `onCheckedChange` fires once for a drag that lands on the side the switch isn't already on, and a change a controlled owner turns down springs back. A press still toggles it (now from the UI thread, like a release, so `onCheckedChange` follows a press a tick later instead of within it), and on the web the click a mouse drag ends with doesn't toggle it back. A change from a press or from the owner now springs on `snappy` too, rather than sliding on the `fast` duration. A vertical swipe that starts on it still scrolls the page.

  _breaking:_ on iOS and Android, a `Switch` outside Gesture Handler's `GestureHandlerRootView` now throws in development (and in a native Jest test), as `Slider` does: wrap the app, and a test's render, in one (`Popover`, `Tooltip` and `Dialog` give their `Modal` one).

- 0697934: Add `Tooltip` to `@reactive/silk-native`, with web `Tooltip`'s `Provider`, `Root`, `Trigger` and `Content` parts. The trigger is a box around the control it explains, so a disabled control still opens it: on the web a mouse resting on it or keyboard focus opens it, and on any platform a press that nothing inside takes does. It closes as the pointer or focus leaves, and on a press outside, Escape or the back button. Adds `mapTooltipStyle`.
- c3b0184: Expand the native renderer with visual primitives (Surface, Card, Heading, Badge, Separator, Avatar, StatusDot, Skeleton, Spinner, Progress) and forms (Input, Textarea, Field, Checkbox, Switch, RadioGroup). Same silk-core recipes as web; RNW a11y compat helpers; Slider deferred to preserve the shared array-valued contract.
- 2a2c7c0: New `Pager.Indicator`: a dot for each page of the `Pager.Root` it is a child of, over the pager's foot, so a reader can see there are pages a swipe away. The shown page's dot widens to a pill in `textPrimary`, and it follows a drag on the UI thread, passing from dot to dot as the pages move. Other dots are `textSecondary`, and a disabled page's is the fainter `borderSubtle`. It only shows: presses pass through it (a drag that starts on it still pages) and screen readers skip it. Write it as a direct child of `Pager.Root`, anywhere among the pages: `<Pager.Root value={page} onValueChange={setPage}><Pager.Page value="a" />…<Pager.Indicator /></Pager.Root>`. Its `style` moves it; `{ position: 'relative', bottom: 0 }` puts it below the pages instead of over them.
- b68dc6e: New `springMotion(spring)`: a one-off `Spring` as the `{ durationMs, easing }` that `useMotion` gives a theme's springs, for a Reanimated CSS transition or keyframes. For example, `const LAND = springMotion({ durationMs: 500, bounce: 0.4 })` plays a bouncier landing than the theme's springs. Prefer the theme's springs through `useMotion` where one fits. Hold the spring in a constant, since it is sampled once per object, and check `useReducedMotion` where that matters.
- 0789bd0: Introduce `@reactive/silk-native`: React Native renderer for Silk with context-based `ThemeProvider` / `SilkProvider`, style mappers from `silk-core` recipes, and exemplar components `Box`, `Stack`, `Inline`, `Text`, and `Button`. Same semantic Theme object and recipe contracts as web; no CSS variables.

### Patch Changes

- 902e471: A horizontal `Field` is as wide as its control and label, so it no longer takes the room of what sits beside it in a row on Android and iOS. Its label column used to grow, which React Native's layout engine turns into the whole row's width.
- 9675f16: On the web, a Popover, Listbox or Tooltip opened inside a Dialog now opens over it, inside the dialog's Modal and its focus trap, instead of behind it. Pressing Escape with one open closes only that layer, not the dialog too.
- 070ca27: A `Field.Label` in a disabled `Field` no longer takes presses, including its own `onPress`. On Android and iOS it used to take the touch anyway, so a `Tooltip.Trigger` around a disabled field never saw a tap on the label.
- 7fa9c04: On the web, a `Pager` and a `Switch` leave the browser its panning across their drag again, as does a `useFlickGesture` view, so a page scrolls when a finger moves across them: Gesture Handler had replaced the `touch-action` they set with `none`. A bottom sheet's panel now leaves the browser its sideways panning (`pan-x`, was `none`), so a sideways scroller inside it scrolls.
- b341f2b: On the web, a `Text` with `onPress` takes the press, as it does on iOS and Android, so a `Tooltip.Trigger` around it no longer opens too. For example, a press on an enabled `Field.Label` inside a `Tooltip.Trigger` now only toggles its control; it used to open the tooltip as well.
- b3a4734: Natively, a `Tooltip.Trigger` inside a line of text is now a span of that text, so it stays on the line, and a tap opens the tooltip beside the line where it landed. A floating layer (`Tooltip`, `Popover`) opened inside text no longer pushes the words around or stops later taps, and a tap outside a floating layer only closes it: the views under it don't see it.
- 788a8b8: `Spinner`, `Skeleton` and an indeterminate `Progress` now loop as Reanimated CSS animations instead of React Native's `Animated`: on a phone they run on the UI thread, and on the web the browser plays them as CSS rather than JavaScript stepping each frame; a `style` that gives `Skeleton` an `opacity` or `Spinner` a `transform` still wins and holds that loop still. `Progress` no longer measures its track, so its sweep starts on the first frame, and in a right-to-left app it now crosses the whole track from the right (it used to start past the right edge and stop short of the left).
- c6e4c0b: `Pager` holds its pages to its own height when it has one, so a scroll view in a page scrolls inside it. On the web the pages grew to their content instead, past the pager's bottom; on native a page with tall content that didn't scroll did the same.
- 865d498: Type every component's `ref` as the host element React Native gives it (`ComponentRef<typeof View>`, `ComponentRef<typeof Text>` or `ComponentRef<typeof TextInput>`), so `.focus()` and `.measureInWindow()` type-check on React Native versions whose components are functions, such as 0.88.
- 93b780f: `Slider` drags on the UI thread: the thumb follows the finger and springs to its step on release, `onValueChange` fires per step, a slide on native waits for a touch slop so a scroll view around it keeps scrolling, a finger in a phone browser drags it rather than scrolling the page, and a value a controlled owner turns down springs back. On Android it needs the app wrapped in Gesture Handler's `GestureHandlerRootView` (`Popover`, `Tooltip` and `Dialog` give their `Modal` one).
- 7c080f9: Native `Slider` keeps its thumb, range and marks under the finger in a right-to-left app, where they had drawn mirrored, and with padding or a border on the slider, which had offset presses. `mapSliderStyle` returns a new `parts` style for the box that holds them; the slider lays that box out left to right in any app, and marks inherit that direction.
- b341f2b: A `Slider` thumb no longer runs past the track's end. Flung toward `max` (or `min`), it used to spring past the end before it came back. It now springs to its step without passing it, and keeps a speed (the finger's, or that of the spring it replaces) only when that heads to the step. So a fling past the step, or a value a controlled owner turns down mid-spring, settles from rest instead of carrying on the other way first.
- b341f2b: On the web, Space toggles a focused `Switch`, `Checkbox` or `RadioGroup` item, and no longer scrolls the page. It works for any `Pressable` whose role is `checkbox`, `radio` or `switch`: Space presses it when the key goes down, once however long it is held, unless the `Pressable`'s own `onKeyDown` prevented the key. react-native-web presses only buttons with Space.
- a9fe655: `silk-native` loads again where the worklets Babel plugin runs (an app's build and its Jest tests): `Slider`'s geometry no longer reads a worklet declared below it, and the sheet's drag no longer spreads into the config its gesture hook takes.
- 2121bab: breaking: themes pinning the blended `hover` hex values (light accent, danger and success; neutral in both schemes) must re-derive them, because hover fills now blend in OKLab instead of sRGB (default light accent `#0f5399` → `#135297`).

  Adds `oklch(l, c, h, alpha?)` (from `@reactive/silk-core`, its `/color` subpath, and `@reactive/silk`), which returns a color's sRGB form and throws a `RangeError` on input out of range. Built-in palettes are kept as OKLCH coordinates and resolve to the same hex; `generateScale` reads its curves from them, so generated scales can move by one hex step. Web `color-mix()` blends in Oklab, which shifts the indeterminate Progress bar's reduced-motion fill slightly.
